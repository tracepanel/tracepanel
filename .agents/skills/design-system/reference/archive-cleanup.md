# Maintain the gap archive

Keep the archive linked from DESIGN.md regardless of its size. Search for relevant
entries and read those records rather than loading the whole archive into context.

Clean up only on an explicit archive cleanup request, within its stated scope.
Preserve decision history, evidence, closure metadata and working links in retained
project documents. Save moved records and repair affected links before removing
their old locations. Git history and hosted permalinks are not prerequisites or
substitutes for retaining these records. A missing or empty archive needs no cleanup.

Report changes and anything retained because removing it would lose history or
break links. Cleanup does not reopen gaps or authorise repairs, commits or pushes.
