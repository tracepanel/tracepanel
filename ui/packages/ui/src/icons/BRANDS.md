# Runtime marks

The console and the panel's pill mark each app with what runs it: the
framework when it names one, else the language (`src/lib/runtime.ts`). A mark
is the owner's logo only where the owner's published policy lets a third
party's product show it, without asking, to refer to that runtime, and only
under that policy's conditions. Every other runtime gets a monogram of ours:
two letters in the console's own type on a faint square, in the theme's icon
colour, with no brand's shape or colour. A page in the browser gets lucide's
globe (ISC), no browser's brand. An app whose SDK sends no runtime gets
lucide's app-window icon.

Product names and logos are trademarks of their owners. Showing one says that
tracepanel supports the runtime; it implies no endorsement or affiliation.

Checked 2026-10-31. A brand moves to "logo" only after its policy is read again
and allows the use; one that requires permission stays a monogram until the
permission is in writing.
